# Contributing

Thanks for your interest!

## Welcome

- **Bug reports** — open an issue with steps to reproduce, device and Android version.
- **Ideas and feedback** — open an issue describing the problem you'd like solved.

## Not accepted (for now)

**Pull requests with code from people other than the author are not accepted at the moment.**

Why: the project is source-available under a non-commercial licence, and the author distributes the official app commercially. Accepting outside code would require a Contributor License Agreement so that contributed code can be used in the official app. Until such a process exists, outside PRs will be closed without review.

You are free to fork and modify the code for non-commercial use under the terms of [LICENSE.md](LICENSE.md) and [TRADEMARKS.md](TRADEMARKS.md).
